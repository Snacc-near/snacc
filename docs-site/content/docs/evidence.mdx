Every claim about the chain on this site rests on a transaction hash that is in the public repos: the [README of the umbrella repo](https://github.com/Snacc-near/Snacc) and its [`docs/evidence-pack.md`](https://github.com/Snacc-near/Snacc/blob/main/docs/evidence-pack.md). This page copies them with explorer links. A hash with no row here is not a claim. NEAR **testnet only**, and `$SNACC` on testnet has no monetary value.

## How to check a hash yourself

{/* Diagram checked against: umbrella docs/evidence-pack.md (section 0, the view and tx helpers, the RPC notes), README ("Live evidence", "On-chain proof"); scripts repo check-links.mjs (archival RPC note). */}

```pele
sequenceDiagram
  autonumber
  actor R as Reader
  participant X as NearBlocks testnet
  participant P as Public RPC
  participant C as snacc-v001.testnet
  R->>X: open the link of a hash
  X-->>R: signer, method, logs with EVENT_JSON
  R->>P: tx(hash, signer), a read-only call
  P-->>R: final status, SuccessValue, receipts
  R->>P: call_function get_global_solvency (a view)
  P->>C: run the view
  C-->>R: drift 0, solvent true
```

- **A transaction.** Open the NearBlocks link, or ask a public RPC (for example `https://test.rpc.fastnear.com`) with the method `tx` and the hash plus the signer account. A good row has a final status with a `SuccessValue` and no failed receipt.
- **A view.** Call `call_function` on `snacc-v001.testnet` with the method name and base64 arguments. Ids go in as JSON numbers.
- **Old hashes.** A regular RPC node forgets old transactions after a few days. Use NearBlocks or an archival node (`https://archival-rpc.testnet.fastnear.com`) for older ones.
- **Offline.** In a clone of the umbrella repo, `npm run verify:thesis` and `npm run demo:replay` read the committed evidence files in `evidence/` and need no keys.

## What this does not prove

- It does not show that the app's wallet flow works. The README keeps a separate column for that, and says it has not been exercised.
- It does not show one-tap play, the Market window, push delivery or a full sign-in with a real wallet.
- Only one epoch was closed, with one dividend contributor. A time-compressed clock was used for the epoch and the starvation windows.
- A valid TEE signature does not prove the key is inside a genuine enclave.
- The 22 checks are the depth of the rules they test. They are not the completeness of the product.
- Nothing is on mainnet.

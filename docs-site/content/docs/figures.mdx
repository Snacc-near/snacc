Each figure is a small machine that does what the contract does. Drag to turn it all the way round, press its buttons, switch on **See-through** to watch the labelled mechanism inside, and zoom with the − / + chip. They run in the browser only: nothing here talks to a chain.

<Callout type="warn" title="Testnet only">
`$SNACC` and NEAR on testnet have no monetary value. The numbers come from the contract code in `Snacc-near/contracts`; where the written design notes differ, the code wins. Amounts are shown at a small demo scale, with `u` = `10^15` yocto-`$SNACC`.
</Callout>

## About the engine

The figures are built on the MIT-licensed [Colorfigures](https://april-zhu.com/colorfigures) engine by April Zhu, recoloured to the Snacc palette. Each one is a single self-contained page under `/figures/` that loads only when you scroll to it, respects the reduced-motion setting, and works with the keyboard and on a phone.

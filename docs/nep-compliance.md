## Summary (honest)

- **In public source with tests:** NEP-141 core (6 methods + `ft_transfer`/`ft_burn`/`ft_mint` events, `ft_mint` live on chain per GLADI-8 — see parity note), NEP-145 (`storage_deposit` / `storage_withdraw` / `storage_balance_of` / `storage_balance_bounds` / `storage_unregister`), NEP-171 (`nft_token`, `nft_transfer`, `nft_transfer_call`), NEP-177 (`nft_metadata`), NEP-181 (`nft_total_supply`, `nft_tokens`, `nft_supply_for_owner`, `nft_tokens_for_owner`), NEP-297 envelope, NEP-245 internal accounting.
- **Parity note:** until 2026-11-09 the NEP-177 `nft_metadata`, NEP-181 enumeration views and NEP-145 `storage_balance_bounds` were live-verified on the deployed wasm but not in the public source (KPI G-22 PASS). Contracts PR #21 closed that gap: the public source exposes the same 67-function ABI as `snacc-v001.testnet`. Parity is structural (ABI identical — the function list is unchanged), not byte-identical wasm. **Current deployment (GLADI-8, 2026-11-09):** code_hash `DMRgsiLJy74V5RS8txLHeJL3T97ivLHuEtY56sSCYmcr` (517,185 B), deploy [`BF3MfUnp…`](https://testnet.nearblocks.io/txns/BF3MfUnpCtcqqXfBWnusDixvHHENBX2FrUHVhbEZQM7V), migrate [`G4fLRtP7…`](https://testnet.nearblocks.io/txns/G4fLRtP7RiPAWueNqHkgkao7NJKAmF3WtLks9jFwmF25) — built from public contracts main [1281154](https://github.com/Snacc-near/contracts/commit/1281154a437181cf657e6ced8db71f73909f7ae8) which includes contracts PR #22 (`ft_mint` on the `incubate_strain` path, string `amount` on `ft_burn`/`ft_transfer`), so these events are live (tx `5JCAmSL7`, `ERBRL4rT`, `FQ6R9fmK`). The previous deployment (code_hash `3DCPVk658pGuRW1FrDZKwrXQr3UHfYG43MoQUfbCwJwt`, 406,495 B, built 2026-11-08) ran the old numeric-amount events with no `ft_mint` and was wiped by this redeploy. The sdk parser accepts both amount shapes (sdk PR #6).
- **Known gaps:** `ft_balance_of` counts account balances only (N141-102); no public `mt_*` surface (recorded design); `near-contract-standards` not used — all surfaces hand-rolled.
- `ft_transfer_call` and `nft_transfer_call` are unit-tested but were not exercised in the gladi run.

## 0. Setup and how to read this page

```bash
# 1) public testnet RPC (rpc.testnet.near.org now answers with a "DEPRECATED" error, code -429, when tested 2026-11-08, so use FastNEAR)
export RPC=https://test.rpc.fastnear.com
# 2) two helpers (bash or zsh; needs curl + python3)
view() { local a=${2:-'{}'}; curl -s "$RPC" -H 'content-type: application/json' -d "{\"jsonrpc\":\"2.0\",\"id\":1,\"method\":\"query\",\"params\":{\"request_type\":\"call_function\",\"finality\":\"final\",\"account_id\":\"snacc-v001.testnet\",\"method_name\":\"$1\",\"args_base64\":\"$(printf '%s' "$a" | base64 | tr -d '\n')\"}}" | python3 -c 'import sys,json;d=json.load(sys.stdin);print(bytes(d["result"]["result"]).decode() if "result" in d else d)'; }
tx() { curl -s "$RPC" -H 'content-type: application/json' -d "{\"jsonrpc\":\"2.0\",\"id\":1,\"method\":\"tx\",\"params\":[\"$1\",\"${2:-snacc-v001.testnet}\"]}" | python3 -c '
import sys,json
r=json.load(sys.stdin).get("result")
if not r: sys.exit("tx not found")
t=r["transaction"]
print("status:",list(r["status"])[0],"| signer:",t["signer_id"],"| call:",[a["FunctionCall"]["method_name"] if "FunctionCall" in a else list(a)[0] for a in t["actions"]])
for o in [r["transaction_outcome"]]+r["receipts_outcome"]:
    for l in o["outcome"]["logs"]: print("  log:",l[:200])'; }
```

`view <method> '<json args>'` prints the contract's JSON. `tx <hash> [signer]` prints status, the called method and the contract's event logs (signer defaults to `snacc-v001.testnet`; the buyer-signed hostile takeover needs `x207-demo-buyer.testnet`). Explorer links open in a browser (`testnet.nearblocks.io` blocks `curl` with HTTP 403, so the RPC commands are the machine-checkable path). The RPC is rate limited: if a command answers with code `-429`, wait a few seconds and run it again.

**One deployment, one gladi.** On 2026-11-09 the contract was **redeployed and migrated** with the SNACC event fix (contracts PR #22: `ft_mint` on `incubate_strain`, NEP-141 amounts as decimal strings) — deploy [`BF3MfUnp…`](https://testnet.nearblocks.io/txns/BF3MfUnpCtcqqXfBWnusDixvHHENBX2FrUHVhbEZQM7V), `migrate` [`G4fLRtP7…`](https://testnet.nearblocks.io/txns/G4fLRtP7RiPAWueNqHkgkao7NJKAmF3WtLks9jFwmF25); migrate reset the state (strain ids restart at 1) and the whole gladi was re-run from zero on it. All 51 txs in `evidence/gladi-manifest.json` belong to this deployment; each was re-fetched on 2026-11-09 and returned `SuccessValue` with the expected signer. `evidence/snacc.wasm` is the exact build that is deployed (C1). `evidence/gladi-kpi.md` is the auto-check of that manifest. Txs from earlier deployments are still on chain but are no longer cited anywhere, because the state they changed no longer exists.

**Sandbox clock — read this before M&A rows.** The contract has an owner-only function `advance_sandbox_clock(hours)` (at most 720 hours per call; it only works when the contract account ends with `.testnet`). The gladi used it to move contract time forward 24 h (to close epoch 0) and then 31 h + 16 h (to let strains starve into the Distressed and Insolvent windows). The mechanics under test are the real ones; the *waiting* was compressed. Every time jump is a tx in the manifest (`advance_sandbox_clock`: [`8YcqqVK3…`](https://testnet.nearblocks.io/txns/8YcqqVK35ubGVZLb1qj8ZLaqS6La7bAcGCafg3ohvuFA), [`3pGR5KDM…`](https://testnet.nearblocks.io/txns/3pGR5KDMqbS6VgnwBhkvUxVJSubTZ5C4YU9kZSK6wWLu), [`5yt47rCD…`](https://testnet.nearblocks.io/txns/5yt47rCDRwkZhEjNi5WDEzWBTgi3kznC5Jar7cpf2ZYC)). `view get_sandbox_clock` returns `[enabled, offset_sec, now_sec]`.
